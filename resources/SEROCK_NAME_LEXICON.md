# SEROCK NAME LEXICON — corroboration prior for AKTREADER
Coordinator-owned resource. Built 28 Jul 2026 from local project sources only.

## ⚠ THE RULE
**This lexicon is a PRIOR, never an authority. It flags disagreements for arbitration priority;
it NEVER overrides what the ink says.** Clerks misspelled; families changed spellings; the same
family appears as Auksztukalska and Uksztukalski two acts apart. A machine read that disagrees
with this lexicon gets *escalated*, not *corrected*. Gold is what the page says.

## Source classes (reliability tiers)
| Tier | Class | Meaning |
|---|---|---|
| 1 | CONSENSUS | ink resolved by the dual-blind + Reader-C protocol (wave RESOLVED appendices) |
| 1b | ACT-READ | ink read in full from a scan by a documented single session (Hélène-project act reads) |
| 2 | JRI | civil-register index rows (human-made index of the same fond; act not always re-read) |
| 3 | OFFICIAL | state documents (1947 naturalization decree, Arolsen/CKŻP registrations) |
| 4 | SURVIVOR-LIST | postwar survivor registrations & lists (CKŻP wykaz, YV survivor pages) |
| 5 | MEMORIAL | Sefer Serock (community memory, compiled 1971; narrative chapters + martyr lists) |
| 6 | MEMOIR | family memory (Hélène's accounts) — precious, and the informe itself documented cases where records corrected it |
